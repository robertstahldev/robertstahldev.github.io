Cube Conquest

Cube Conquest is a Unity-based 3D strategy game focused on territory control, turn-based decision-making, and AI-driven opponents. The project emphasizes an object-oriented design, modular systems, and scalable gameplay logic. It was developed as a personal engineering-focused game project to explore interactive systems, maintainable Unity architecture, and real-time game logic.

  • Procedural grid-based board generation
  • Adjacency and selection rules with hover feedback
  • Turn-based gameplay system with AI decision logic
